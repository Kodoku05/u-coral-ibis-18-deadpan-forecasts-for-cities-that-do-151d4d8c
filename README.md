One deadpan weather forecast for the invented city of Gutterhollow:

> Gutterhollow: snow will hang six feet above Market Street until noon; double-decker buses are diverted while council gritters await developments.

Run `node main.ts` to write `/output/entry.txt` (145 ASCII characters, no trailing newline). Set `MAKEFUN_OUTPUT_DIR` to override the output directory. Uses only Node standard library modules; no dependencies.
